CTRL+Z｜平行人生實驗室 AR 2.0

檔案：
- index.html：AR 網頁與互動遊戲
- poster.png：本次提供的原始海報
- targets.mind：需自行使用 MindAR Compiler 由 poster.png 產生，再放在同一層

步驟：
1. 開啟 https://hiukim.github.io/mind-ar-js-doc/tools/compile
2. 上傳本資料夾 poster.png（務必是同一張圖）
3. 下載編譯結果，命名 targets.mind（注意不是 targets (2).mind）
4. 將 index.html、poster.png、targets.mind 上傳到 GitHub 儲存庫根目錄。
5. 啟用 GitHub Pages，使用手機 HTTPS 網址開啟，允許相機權限。
6. 用手機掃描印出的 poster.png 或另一個螢幕上的相同海報。

可先點「先玩劇情體驗版」測試選擇、數值與 CTRL+Z 重選，不需要相機。
若能開相機但無法辨識，先檢查 targets.mind 是否是由這次的 poster.png 編譯。
本專案需連網載入 A-Frame 與 MindAR。
